01. Concept & Paradigm Shift

AI Agent(에이전트)란 무엇인가? — 기존 챗봇과의 결정적 차이

단순 대화형 챗봇에서 '도구를 쓰는 디지털 실무자'로 진화

💬 기존 단순 AI 챗봇 (LLM 단독)

  • 사전 학습된 일반 상식으로만 텍스트 답변 생성 ("말만 하는 사전")
  • 사내 실시간 데이터 조회 불가 (오늘 전표, 시운전 로그, 하자이력 모름)
  • 모든 질문을 외부 클라우드로 전송하여 원가·설계·고객 정보 유출 우려
  • 사용자가 물어볼 때만 수동적으로 응답 (실시간 감시·선제 알림 불가)

🤖 제안하는 기업용 AI Agent (Tool + RAG + Action)

  • 질문 의도를 분석하여 사내 DB · 센서 모델 · 매뉴얼 도구를 직접 실행
  • ERP SQL 자동 생성, MES 시계열 구간 분석, 하자점검보고서 즉시 검색
  • 사내 로컬 LLM 기본 처리(보안·무과금) + 필요시 외부 AI API 선택 호출
  • 설비 이상 징후 포착 시 원인 진단 후 담당자 휴대폰(텔레그램) 선제 경보
비교 항목 기존 단순 AI 챗봇 사내 구축형 AI Agent (본 제안 모델)
작동 메커니즘 질문 입력 → LLM 텍스트 추론 → 단순 답변 의도 파악(Router) → 사내 플러그인(SQL/RAG/ONNX) 실행 → 종합 리포트 & 액션
환각(거짓말) 통제 모르는 사내 정보도 그럴듯하게 지어내어 답변 실제 사내 DB 조회 결과와 매뉴얼 원문(출처 명시)에 근거해서만 정확히 답변
보안 및 운영비 질문마다 외부 API 종량제 과금 & 데이터 외부 전송 사내 로컬 LLM으로 민감 데이터 100% 내부 처리 (고난도/OCR만 외부 API 선택 사용)

03. Background & Pain Points

왜 항온항습기 제조 · 유지보수에 AI Agent가 필요한가?

맞춤형 수주 제조(ERP/MES)와 장기 현장 유지보수(A/S)의 결합
과제 1 · 현장 유지보수(A/S)

출동 기사 숙련도 편차 및 암묵지 유실

  • 여름철 고압 차단(High Pressure Trip), 겨울철 가습기/히터 불량, 결로 등 계절성 장애 빈발
  • 수천 건의 하자점검보고서가 쌓여 있으나 현장에서 유사 증상(조치전 온도·고압)을 즉시 찾기 어려움
  • 신입/초급 기사가 현장에서 숙련자에게 전화로 물어봐야 하는 비효율 발생
과제 2 · 시운전 및 원격 관제

24시간 수신로그 및 센서 감시의 한계

  • 납품 장비 및 시운전 라인에서 5분 주기로 수집되는 rclog와 온습도·전류·진동 데이터의 방대한 양
  • 사람이 그래프를 일일이 눈으로 보고 언제 가동이 멈췄고 언제 급락(Anomaly)했는지 판별하기 불가능
  • 컴프레서 소손 등 치명적 고장이 발생한 뒤에야 사후 출동하는 악순환
과제 3 · 경영·원가·계약 분절

ERP · MES · 보전 이력의 데이터 사일로

  • 특정 고객사 납품 장비의 제조 원가(ERP), 시운전 기록(MES), 무상보증 만료일 및 고장 이력이 각각 분리됨
  • 거래처별 미수금, 부품(컴프레서·냉매·필터) 매입 단가 추이를 보려면 복잡한 전표 화면을 수작업 집계해야 함

🎯 도입 목표: "현장 기사의 스마트폰과 관리자의 PC에 15년 경력의 AI 수석 엔지니어를 탑재"

사내에 축적된 하자점검보고서 · 장비 매뉴얼 · 15년치 업무일지 · ERP 전표 · 실시간 센서 로그를 단일 AI Agent 허브로 통합하여, 자연어 질문 한 번으로 진단부터 원가 분석, 모바일 경보까지 즉시 해결합니다.

연계 1 · 장비유지보수(EAM/PdM) 에이전트

🛠️ 항온항습기 하자진단 & ONNX 실시간 예지보전

  • 하자점검보고서 하이브리드 RAG 검색:
    장비명, 장애내용, 시정, 재발방지대책, 조치전_온도, 조치전_고압 데이터를 통계 SQL + pgvector 의미 검색으로 결합 조회
  • 계절별/월별 다발성 고장 자동 분석:
    하절기(응축기 코일 오염·고압차단) / 동절기(가습기·히터) 장애 점유율 및 사전 점검표 자동 생성
  • ONNX 딥러닝 실시간 센서 이상 감지:
    • 센서 1 (model_sensor1_hvac.onnx): 항온항습기 온습도·고압/저압 이상 추론
    • 센서 2 (model_sensor2_motor.onnx): 컴프레서·송풍팬 모터 전류/진동 추론
  • 장비 매뉴얼 RAG 연동: 제어기 에러코드·부품 교체 매뉴얼 즉시 제시
💬 현장 기사 질의 예시: "조치전 온도가 28도 이상이고 고압이 높게 걸리면서 멈추는 장애 사례와 해결책 찾아줘" → 과거 유사 사례 15건 및 조치법 3초 내 응답
연계 2 · MES / 원격 수신로그 에이전트

🏭 시운전 · 원격 수신로그 자동 구간 분석 & Grafana 관제

  • Gaps & Islands 시계열 상태 머신 자동 분류:
    5분 주기 수신로그(rclog)의 전후 수량을 윈도우 함수(LAG/LEAD)로 비교하여 4대 상태를 DB 레벨에서 자동 판별:
    • 🟢 RUNNING (정상 가동) / ⚪ IDLE (대기·휴지)
    • 🟡 TRANSITION (과도 구간) / 🔴 ANOMALY (돌발 이상 급락)
  • 구간별 지속시간 · 평균/최대치 · 누적 생산량 자동 집계:
    사람이 차트를 일일이 찾지 않아도 오늘 몇 시부터 몇 시까지 몇 분간 돌발 급락이 발생했는지 표로 즉시 요약
  • 외부/모바일 반응형 Grafana 실시간 대시보드 내장:
    사내 PC 및 외부 스마트폰에서 Kiosk 전체화면 차트 실시간 모니터링
📊 관제 효과: 수만 건의 원시 로그를 의미 있는 가동/이상 구간 단위로 자동 압축하여 일일 시운전·가동 리포트 즉시 생성

연계 3 · ERP 경영·회계·계약 에이전트

💰 자연어 Text-to-SQL 재무·원가·계약 분석

  • 복잡한 전표·원장 화면 없이 대화형 즉시 집계:
    질문 의도에 맞춰 에이전트가 PostgreSQL ERP DB(`account`)의 스키마를 참조해 안전한 SELECT SQL을 자동 작성·실행
  • 거래처별 매출·매입·미수금·원가율 실시간 분석:
    컴프레서·열교환기·제어보드 등 핵심 자재 매입 추이 및 프로젝트별 수익성 즉시 리포팅
  • 유지보수 계약 및 무상보증 만료 연계:
    고객사별 납품 장비의 무상 A/S 종료 도래 건, 유상 유지보수 재계약 대상 목록 자동 추출
  • Vision AI 명함·거래처 자동 등록:
    스마트폰으로 촬영한 명함을 OCR로 파싱하여 주소록/거래처 DB에 즉시 등록
🔒 안전 가드레일(Safety Guardrail): 에이전트 SQL은 읽기 전용(Read-Only)만 허용하여 기간계 재무 데이터 훼손 위험 원천 차단
연계 4 · 전사 지식 RAG & 텔레그램 현장 비서

📱 15년치 기술·업무 노하우 자산화 및 모바일 양방향 연동

  • 15년치 업무일지 · 프로젝트 · 자료실 통합 벡터 검색:
    과거 15년간 축적된 현장 공사 기록, 시운전 특이사항, 도면/기술문서를 pgvector(3,072차원)로 임베딩하여 퇴사자/숙련자 암묵지 영구 보존
  • 텔레그램 봇(@bnimemo_bot) 실시간 양방향 연동:
    • AI 분석 결과를 텔레그램 지원 HTML로 자동 변환 및 3,500자 스마트 청킹([1/N]) 발송
    • 1클릭 [내 폰 전송] 및 부서 [메모 채널 공유] 분리 구성
  • 프롬프트 핫리로드(Hot-Reload) 관리:
    서버 재시작 없이 웹 화면에서 도메인별 에이전트 지침(.md)을 즉시 수정·튜닝
